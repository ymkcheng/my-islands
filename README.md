# 開發流程群島（I3840 W7）

HCI 設計開發流程的島嶼遊戲（課程內部也叫五步島）。打開 `index.html` 就能玩，不用安裝、不用帳號。

2026-10-29 照課程自己的規格從零寫成，**沒有使用造島工坊的造島包，也沒有參考它產生的網站程式**。規格只取自課程工作室裡我們自己的文件：

- `課程/I3840/115-1/教學材料/W7-五步島-流程與遊戲規則.md`（五步、守門人、怪獸、交接物、過關條件、遊戲規則）
- `課程/I3840/115-1/教學材料/W7-導演本-新模式-v0.md`（主管報告七段、設計開發報告八章、Kevin 的紅筆）
- `課程/I3840/115-1/自檢/W7-五步島-OpenCode實跑-2026-10-29.md`（Kevin 定的修改：拿掉完整對話與提示、選擇題換守門人、順序上鎖、交接物、任務卡、自帶金鑰）

## 玩法

1. 取冒險者代號、選樣子，貼上課堂完成的主管報告。左上角出現這一趟的任務
2. 用方向鍵或 WASD 走路（手機與平板畫面右下有方向鍵），走到守門人身邊才開始那一步；點島名只會把鏡頭移過去。照順序過五座島，島與島之間有橋，橋頭的門要等前一座島過關才打開。每座島有守門人和一隻常犯錯怪獸；下一座島要先把上一座拿到的交接物交出去
3. 去問島可以跟小安聊天（要玩家自己的 Gemini 金鑰），問對了會翻開三張卡
4. 每座島寫完交給守門人判斷，最多三次；一定要貼金鑰（2026-11-02 拿掉自我檢查）。守門人連續兩次叫不到，可以寫卡在哪、為什麼，印出寫到這裡的報告
5. 五枚島章到手，把測試紀錄交給鐘塔，打開回頭修改島：五步都能改，寫第六、七章，印成 PDF

附帶：經驗值與等級、背包、接關碼（換電腦接著玩，不含金鑰）、減少動態。

## 畫面

低多邊形的 3D 群島，用 three.js r158（MIT 授權，放在 `js/vendor/`，不用連網）。可以拖曳旋轉、滾輪或兩指縮放，點島名登島時鏡頭會飛過去拉近；下方有「回到全景」「跟隨角色」。上方可以切換晨光、海霧、夜海三種天色，夜裡路燈和窗戶會亮。

每座島有自己的地標：去問島是小村子和水井、說清楚島是燈塔、想辦法島是風車、做出來島是冒煙的工坊、給他用島是帳篷和觀察台、中央是鐘塔廣場。每座島都有碼頭、路燈、樹、走動的居民和守門人；怪獸繞著島飄，過關後消失。航線是一串浮標，過關的變金色，沒開的島是灰的。遠方有被霧遮住的山和帆船。主角有四種樣子可以選。電腦沒有 WebGL 時自動退回平面地圖。

## AI

- 模型：`gemini-3.6-flash`（2026-10-29 取自 Gemini 官方價目頁的免費模型清單），在 `js/content.js` 的 `model` 改
- 金鑰只存在玩家瀏覽器，不在任何檔案裡
- 2026-10-29 測試用的是模擬的 Gemini 回應：流程、翻卡、守門人第一次不過第二次過、自我檢查、列印、重新整理後進度還在、手機 375 寬都驗過。**真的金鑰還沒用這一版試過**

## 課堂報告怎麼放進來

「我的報告」視窗可以貼 Google 文件的連結（文件要設成「知道連結的任何人」可以檢視），按「讀進來」；也可以直接複製貼上。2026-10-29 用一份真的公開文件從 `http://127.0.0.1` 與 `https://example.com` 兩種網址讀過都讀得到，所以放上 GitHub Pages 也讀得到。直接雙擊打開 `index.html`（網址是 file://）讀不到：2026-11-02 用無頭 Chrome 試，瀏覽器擋下來（Failed to fetch）。雙擊打開時請把文件全選複製、直接貼進去。
